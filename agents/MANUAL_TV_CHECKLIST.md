2. Select **Alex** → hub shows 6 tiles; focus ring visible when moving.
3. Open **Films** → hero + rows; OK on poster → film detail.
4. Favoris / À regarder plus tard toggle; Back returns to Films.

6. Top-right **Actualiser · DÉMO** → banner states simulation / no IPTV server.
7. **Menu** → hide a provider group / reorder rows → catalog updates for Alex only.
8. Switch to **Sam** via profile chip → different row set / kids group hidden by default.
9. Hub Back → profiles; system Back mirrors on-screen Back on section/detail.
